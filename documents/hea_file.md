## HEA文件头
```text
JS00001  12  500  5000
```
HEA文件第一行记录了文件名称 导联数量 采样率（单位时间采样范围） 采样数量

| 字段 | 值 | 含义 |
| --- | --- | --- |
|文件名|JS00001|数据文件名（对应 JS00001.mat）|
|导联数量|12|这里共12导联|
|采样率|500|500 Hz（每秒500个采样点）|
|总采样数量|5000|每个导联5000个点，即 10秒 的记录（5000÷500=10s）|

## HEA信号行
以第一导联为例
```text
JS00001.mat  16+24  1000/mV  16  0  -254  21756  0  I
```
| 字段   | 值           | 含义                             |
|------|-------------|--------------------------------|
| 文件名  | JS00001.mat | 信号数据存储在此 .mat 文件中              |
| 格式   | 16+24       | 16位整数编码，字节偏移量为24               |
| 增益   | 1000/mV     | 1000 ADC单位 = 1 mV（即精度0.001 mV） |
| 位数   | 16          | 16位分辨率                         |
| 基线偏移 | 0           | ADC零点偏移                        |
| 初始值  | -254        | 第一个采样点的原始ADC值                  |
| 校验和  | 21756       | 所有采样点之和（用于数据完整性校验）             |
| 块大小  | 0           | 0表示连续存储                        |
| 导联名  | I           | 标准肢体导联 I (共12导联，分别为 I、II、III、aVR、aVL、aVF、V1～V6)           |
## HEA注释区（补充信息）
\#开头的区域为注释区，这里一般会记录对应ECG的一些补充信息，如患者临床信息
